# AI-Powered Chest X-Ray Diagnostic Analyzer

An end-to-end Deep Learning application designed to assist clinical workflows by identifying radiological patterns consistent with **Pneumonia** from digital chest X-ray scans. Built using PyTorch, ResNet18 Transfer Learning, and a Streamlit interactive frontend.

## 🚀 Key Architectural Features
* **Core Framework:** PyTorch & Torchvision
* **Architecture:** ResNet18 Deep Convolutional Neural Network (Transfer Learning)
* **Frontend Web Application:** Streamlit
* **Target Classification:** Binary classification mapping (`0: Normal Health` vs `1: Pneumonia Presentation`)

## 📁 Repository Framework
* `app.py`: Streamlit application engine orchestrating frontend interactions and pipeline workflows.
* `model.py`: Model definition logic customizing deep feature maps for specific radiographic tasks.
* `requirements.txt`: Specified library versions required to replicate the environment.

## ⚙️ Setup and Execution
1. Clone the repository framework:
   ```bash
   git clone https://github.com
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the interactive live web application:
   ```bash
   streamlit run app.py
   ```

## 🛑 Medical Disclaimer
This software framework is developed solely as a technical portfolio project demonstrating Artificial Intelligence methodologies in computer vision. It is **not** evaluated by Health Canada or the US FDA and is not intended for diagnostic purposes or active clinical decision support.
